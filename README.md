# 🖥️ C Programming Journey

My journey into mastering **C programming** — building a strong foundation for **Embedded Systems, Robotics, and low-level system design**.

This repository contains structured notes, hands-on exercises, and practical projects focused on understanding how software interacts with hardware.

---

## 📌 About

C is a fundamental language for systems programming and embedded development.
Through this repository, I aim to develop a deep understanding of:

* Memory management
* Data representation (Binary, Hex, ASCII)
* Low-level programming concepts
* Hardware interaction principles

These concepts are essential for working with microcontrollers and building real-world embedded systems.

---

## 📂 Repository Structure

```
basics/              → Variables, loops, conditionals  
functions/           → Modular programming, recursion  
arrays_pointers/     → Arrays, strings, pointers  
data_representation/ → Binary, Hex, ASCII, conversions  
file_processing/     → File I/O in C

mini_projects/       → Applied projects combining concepts  
```
